Get Overlay Stream working.

Check the setup steps below before reporting a problem.

Before you start

  1. Allow camera, microphone, and add-only Photos access.
  2. Enter an HTTP or HTTPS browser-overlay address.
  3. Select YouTube or Facebook.
  4. Enter the matching streaming server and stream key.
  5. Confirm the preview before recording or going live.

Recording does not start

Confirm all three permissions are enabled in iOS Settings and that the overlay loads in the preview. Close and reopen the app after changing permissions.

The overlay does not load

Open the overlay address in Safari on the same iPhone. Local network addresses must be reachable from the phone, and HTTPS is recommended for public overlays.

The live stream does not connect

Verify the destination, server address, and stream key in the streaming provider's dashboard. Generate a new stream key if the existing one may have been exposed. Never include a stream key in a screenshot or support request.

Contact support

Report reproducible problems through the project's support tracker. Include the iPhone model, iOS version, destination, and the exact error message.

Open a support request

Support requests are public. Remove stream keys, private URLs, credentials, and personal information before submitting.
